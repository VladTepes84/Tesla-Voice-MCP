# Early Tesla OAuth prototype

This directory contains a historical OAuth prototype for reference. **The main maintained MCP entry point is under `simulator/`**, including its HTTPS handler, guarded tool catalog, Tesla Fleet integration, planning modules and current tests.

Do not use this prototype as the default installation path or assume its behavior matches the current remote MCP runtime. Begin with the [repository README](../README.md), [Beginner's Guide](../docs/BEGINNERS_GUIDE.md) and [Complete installation](../docs/INSTALLATION.md).

Never place Tesla client secrets, access/refresh tokens, private keys, vehicle identifiers, personal addresses or real location data in source files.
